# Simple P2P Messaging

Allows for two users to connect their devices and talk to each other. It will have a folder that saves the conversations of each day.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Have Python installed on both devices
2. One will be the one to start the server
3. This user will put both IP's into the whitelist
4. Change the server IP in both client program's to be the server's IP

Instructions for using the software:

1. Have the server user run the server
2. Run the program on both user's devices
3. Input a username and connect to each other
4. Start chatting!
